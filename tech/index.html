FAQ

Answers up front.

How do you run a software project?+
In four stages — Define, Plan, Release, Improve. Requirements become a backlog, we build in sprints, and every release ships with release notes and a change log.
Which platforms do you build on?+
WordPress for content-driven websites so your team can update pages easily, and custom code for web apps, mobile apps and games.
Where do you host, and how secure is it?+
On AWS behind Cloudflare's DDoS protection, deployed with Docker through GitLab CI, and scanned with tools like Nessus and Mozilla Observatory.
What happens after launch?+
Our care plan covers backups every two days, script and CMS updates, content updates and 24/7 monitoring — we notify you within an hour if anything goes wrong.
Can you help us rank on Google?+
Yes — every site is built SEO-ready, and our five-step SEO programme adds keyword research, UX and content improvements, with weekly reports.
